## [v0.18.0] - 2026-10-03

### Highlights

- **Repository access listing**: `repo.ListNonMemberOrgRepos` answers "which repositories have I been granted access to in organizations I don't belong to?", backed by new `clientv1` methods for the authenticated user's repositories and organization memberships, and exposed as the `gogithub repo-access` CLI command
- **OAuth app authentication via goauth**: organizations can forbid personal access tokens; the new `auth/credentialsset` package obtains an OAuth app token from a goauth credentials set file using the authorization code grant, and `errors.IsTokenPolicyError` plus `repo.CheckAccess` make the policy block visible instead of looking like a missing repository

### Added

- [clientv1] `ListAuthenticatedUserRepos(ctx, opts)` wraps `GET /user/repos`, including private and collaborator-granted repositories, with `Visibility` and `Affiliations` filters; results include `Repository.Permissions` ([`1d900fb`](https://github.com/grokify/gogithub/commit/1d900fb))
- [clientv1] `ListOrgMemberships(ctx, opts)` wraps `GET /user/memberships/orgs`, with a `State` filter ([`1d900fb`](https://github.com/grokify/gogithub/commit/1d900fb))
- [types] `Repository.Permissions` with `RepositoryPermissions.Highest()`, `OrgMembership`, and constants for owner types, permission levels, membership states, and repository affiliations ([`1d900fb`](https://github.com/grokify/gogithub/commit/1d900fb))
- [errors] `IsTokenPolicyError(err)` detects a 403 caused by an organization policy that rejects the token type (e.g. classic PATs forbidden); `Message(err)` extracts the message GitHub returned ([`f6f98a8`](https://github.com/grokify/gogithub/commit/f6f98a8))
- [repo] `ListNonMemberOrgRepos`, `FilterNonMemberOrgRepos`, and `MembershipOrgLogins` list and filter repositories owned by organizations the user is not an active member of ([`1016187`](https://github.com/grokify/gogithub/commit/1016187))
- [repo] `CheckAccess(ctx, client, owner, name)` reports access to one repository as `granted`, `not_visible`, or `blocked_by_token_policy`, probing the owner on a 404 to tell the last two apart ([`1016187`](https://github.com/grokify/gogithub/commit/1016187))
- [auth/credentialsset] `NewClient` and `NewToken` create clients from a goauth credentials set account, using a stored token or the authorization code grant via an `AuthCodePrompt`; `PromptReadWriter` provides a command-line prompt and `RedirectURL` the hosted redirect page ([`22a3ee7`](https://github.com/grokify/gogithub/commit/22a3ee7))
- [cli] `gogithub repo-access` lists accessible repositories with permission levels; `--non-member-orgs` filters to organizations the user is not a member of, `--repo owner/name` checks specific repositories, `--creds`/`--account` authenticate as an OAuth app, and `-f json` emits JSON ([`2def571`](https://github.com/grokify/gogithub/commit/2def571))

### Changed

- [cliutil] `GitStatusShortLines` runs git in the target directory with `-C` instead of changing the process working directory, uses the stable porcelain format, and omits empty lines; `GitRmDeletedLines` returns commands without trailing newlines and `GitRmDeletedFile` replaces the output file ([`29efed1`](https://github.com/grokify/gogithub/commit/29efed1))

### Fixed

- [cliutil] `bulk_git_rm` takes the repository directory as `--dir` (default: current directory) instead of a hardcoded local path, and prints `git rm` commands to stdout or to `--out` ([`bdf2ea3`](https://github.com/grokify/gogithub/commit/bdf2ea3))

### Dependencies

### Documentation

- Documented repository access listing, `CheckAccess`, OAuth app authentication, token policy errors, and the `repo-access` CLI command across the clientv1, repo, auth, errors, and CLI guides ([`6f9b0cf`](https://github.com/grokify/gogithub/commit/6f9b0cf))
- Added coverage badge to README ([`bacd650`](https://github.com/grokify/gogithub/commit/bacd650))

### Tests

## [v0.15.0] - 2026-08-01
